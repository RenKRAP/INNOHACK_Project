# KIM-LDAPS 1km 예보

> 과거 구현 기록입니다. 현재 최신 예보는 사용자가 지정한 Open-Meteo JMA MSM 5km·기본 예보·Marine 조합을 사용합니다. 아래 KIM 인증키·요청·오류 안내는 비활성 어댑터에만 해당합니다. [현재 예보 안내](open-meteo-forecast.md).

2026-11-27 구현. 기본 최신 예보는 GFS 대신 기상청 KIM-LDAPS 원격자 1km를 요청한다. 2026년 7월 과거 분석과 저장 JSON은 기존 GFS 자료로 유지한다. 격자를 1km로 보간해 정밀 자료처럼 표시하지 않는다.

## 실행 설정

1. [기상청 API허브](https://apihub.kma.go.kr/)에서 인증키를 발급받고 KIM 자료 이용을 신청한다.
2. 프로젝트 루트의 `.env.example`을 `.env`로 복사하고 `KMA_API_KEY=발급받은키`를 입력한다. 기존 `.env` 또는 `.env.local`이 있으면 필요한 항목만 추가한다. 기존 프로세스 환경변수, `.env.local`, `.env` 순으로 우선한다. 두 파일 모두 Git에서 제외된다.
3. `npm.cmd run dev`를 실행한다. 키 변경 시 서버를 재시작한다.

키는 로컬 서버에서만 읽으며 브라우저나 출처 메타데이터에 포함하지 않는다. `.env.local`은 Git에서 제외된다. 키가 없으면 HTTP 503 `KMA_KEY_REQUIRED`와 설정 안내를 표시한다. 키 없는 상태에서도 7월 과거 분석은 사용할 수 있다. 배포와 원격 `server/` 변경은 하지 않았다.

## 자료 계약

- API: `https://apihub.kma.go.kr/api/typ06/url/nwp_nc_tser_down.php`, `group=KIML`, `nwp=l010`, `dataType=TEXT`. 실조회에서 확인한 모델·출력 형식을 명시한다. CSV도 공식 지원 형식이며 파서는 두 형식을 모두 처리한다.
- 지상 `data=U`: T2, RH2, U10, V10, SST. 기압면 `data=P`: 1000/975/950/925/900/850hPa의 RH와 GPH.
- `tmfc`는 UTC 발행 시각, `hf1=0`, `hf2=48`, `hf_int=1`. 위경도에 가장 가까운 격자를 요청한다. 발행 0~48시간을 KST 최대 49개 시각으로 변환한다.
- 최신 6시간 주기에서 3시간을 뺀 발행 시각을 먼저 요청한다. **3시간은 구현상의 여유값이며 공식 제공 지연 보장이 아니다.** 명시적인 자료 없음 응답일 때만 직전 6시간 발행으로 한 번 재시도한다. 인증·형식·연결·HTTP 오류에는 이전 발행으로 우회하지 않는다.
- 좌표당 정상 경로는 17회 요청이다. T2로 발행 가용성을 먼저 확인하고 나머지를 요청한다. 선택 지점과 기본 지점을 합쳐 동시 요청은 최대 2개다. 요청별 시간 제한 45초, 좌표별 예보 캐시 5분(전체 최대 32개), 중복 진행 요청을 합친다. API허브 이용 한도는 계정 조건을 확인해야 한다.
- 응답 바이트를 `Content-Type`의 문자셋에 따라 해석한다. 실제 TEXT 응답의 `EUC-KR`, 주석으로 시작하는 열 이름, 공백 구분, 과학적 표기 숫자를 처리한다. CSV의 `tmef`와 TEXT의 `tm`은 UTC 예보 시각이며, `tmfc`와 예보 시각이 요청 발행·예보 시간에 일치하는지 검사한다.
- HTTP 200이어도 본문이 `# ERROR: CGI …`이면 예보 자료가 아닌 기상청 처리 오류다. 동일 좌표·발행·항목을 0.5초, 1초 간격으로 최대 두 번 추가 요청한다. 계속 실패하면 `KMA_TEMPORARY`로 안내한다. 인증 오류와 잘못된 자료 형식은 이 재시도 대상이 아니다. 실패한 결과는 캐시하지 않는다.
- T2/SST는 K→°C, RH는 %, GPH는 m, U/V는 m/s로 처리한다. Magnus 식으로 이슬점, U/V로 풍속과 기상학적 풍향을 계산한다. 결측·비정상 단위는 가짜 값으로 채우지 않는다.
- 육지 SST가 결측이면 서쪽은 (35.14, 129.125), 동쪽은 (35.148, 129.165)의 연안 해상 참조점으로 동일 발행 SST를 한 번 더 요청한다. 경계 경도는 129.14다. 참조점 요청 좌표와 경고를 기록한다. 남은 SST 결측은 점수를 미확정으로 표시한다. 해상 참조점의 실제 격자와 자료 가용성도 인증 응답으로 확인해야 한다.
- 모델명·명목 해상도·발행 시각·수집 시각·요청 좌표·출처·결측 경고를 응답에 보존한다. 현재 파서는 격자 중심 좌표를 메타데이터로 추출하지 않으므로 `grids.atmosphere/marine`을 null로 표시한다.

## 검증 상태와 해석

2026-11-27 인증된 실조회에서 기본 좌표 (35.1595, 129.1604)의 17개 항목과 49시간 예보 수신을 확인했다. 이번 점검에서도 `nwp=l010`과 TEXT 출력을 적용한 요청으로 전체 항목 수신과 변환에 성공했다. 실제 TEXT의 지상·기압면 열 구조는 다음과 같다(기압면은 별도 `lvl_lst` 주석 포함).

```text
#     tmfc   hf            tm        lon        lat        value
2026112706    0   2026112706  129.15686   35.15617  2.88900e+02
```

CSV 열 `tmfc,hf,tmef,ix,iy,lon,lat,value`도 지원한다. 실제 열 구조, EUC-KR 인증 오류, 시각 불일치 거부, 49시간 자료 변환 및 해무 점수 계산, CGI 재시도 상한을 포함해 전체 테스트 41개와 빌드가 통과했다.

단, 동일 요청이 정상 자료와 HTTP 200 CGI 오류를 번갈아 반환했다. 최종 로컬 HTTP 통합 조회에서는 해운대·수영구 모두 CGI 재시도를 소진해 HTTP 502 `KMA_TEMPORARY`를 반환했다. 현재 오류를 자료 형식 불일치만으로 설명할 수 없으며, 형식 변환 수정이 기상청 서버의 CGI 장애까지 해결한 것은 아니다. 실자료의 지속적인 제공 안정성은 보장하지 않는다. 알 수 없는 형식은 오류로 표시하며 GFS로 조용히 대체하지 않는다.

1km는 수평 모델 격자 간격이다. SST 경계장의 독립 관측 간격, 수직 해무층 해상도, 건물별 시야 정확도를 뜻하지 않는다. 인접 클릭은 같은 격자여서 점수가 같을 수 있다. 관측 고도 입력과 해무층 상단 비교는 유지하지만 지형·건물 차폐·시선 방향은 계산하지 않는다. 현재 지도는 해운대·수영구 해안 일부 범위다. 해무 관측 라벨이 없어 점수는 검증된 발생확률이 아니다.
