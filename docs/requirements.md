# 요구사항 대응표

검토 자료: 2026-11-27 수정된 `source/OnSeafog.docx`, `source/toDo_API.png`, `source/INNOHACK-평가기준.png`. 배포 항목은 사용자의 지시에 따라 수행하지 않았다. 새 문서의 고정 지도 요구사항을 적용해 이전 지도 이동·확대 동작을 제한했다.

| 요구사항 | 구현 및 검증 위치 |
|---|---|
| MAIN001 해운대·수영구 상세 고정 지도 | Leaflet·OpenStreetMap 타일. 이동·확대 제한, 원형 강조는 선택 위치만 표시. 타일 실패 재시도 제공 |
| 지도와 페이지 스크롤 분리 | 지도 내부 휠 클릭·회전의 기본 동작 차단, 지도 외부 기본 스크롤 유지 |
| MAIN002 지점별 시간 점수·해무 표시 | 각 좌표의 기상자료로 동일한 선택 시각의 점수를 계산하고 조건 충족 시 해무 아이콘 표시. 조회 실패·시각 누락은 미확정 |
| MAIN003 선택 사이드바·고도 저장 | 선택 좌표별 관측 해발고도 입력·브라우저 저장·초기화, 해무층과 높이 비교. 저장 불가 시 현재 세션에 유지 |
| MAIN004 고층 건물·해수욕장·해안 1km 이내 | 아이파크·남천 엑슬루타워·엘시티, 해운대·광안리. 수동 해안 참조점까지 근사 직선거리는 모두 1km 미만이며 정밀 해안선 판정은 아님 |
| EXP001 2026년 7월 시간별 분석 | 실 API에서 수집한 744시간 저장, 날짜·시간 선택·재생·그래프 |
| 공기·해수 온도차, 습도, 남동풍 조건 | `model/fog-model.js`, 요인별 기여도 표시와 모델 테스트 |
| 고도별 RH 90% 기반 상단 | GFS 기압면 고도·습도, 지상 연결층의 첫 경계 보간. KMA 기압면 대신 현재 지원되는 GFS 입력 사용 |
| 전망 지점 선택 및 고도 비교 | 5개 지점과 임의 클릭 좌표. 관측 고도가 해무층 상단 추정 범위보다 높으면 해무 위, 그 이하면 해무 속으로 표시. 오차 범위 안에서는 시야가 달라질 수 있음을 설명. 미입력 시 높이 판정 보류 |
| API 연동 | 좌표별 과거 기상·해양 자료와 최신 3일 예보, 좌표·모드별 캐시·오류·재시도 |
| 결과 확인·공유 | 조건 설명 대화상자, 날짜별 CSV 내보내기 |
| 예측 검증 | 규칙·결측·고도 경계·API·서버·평가 로직 자동 테스트. 관측 평가 CLI 제공 |
| 창원 고층·천리안 2A·산지 AWS와 실측 검증 | 추가 API 연동 미완료. 창원 관측 인증키·위성 제공 방식·적합한 산지 AWS와 독립 라벨 확보 필요. 검증 방법과 한계는 모델 카드에 명시 |
| 외부 서버 배포 | 미수행. 로컬 루프백 주소에서만 서비스 |

원문 고도 비교의 부등호는 설명과 반대여서 물리적 의미에 따라 관측자가 해무층보다 높은 경우를 ‘해무 위’로 구현했다. 건물 전체 높이를 관측자의 해발고도로 사용하지 않는다. 아이파크 292m는 건축가 공개 자료의 건물 높이 참고값이며, 사용자가 실제 관측 고도를 입력해야 한다. 해수욕장 5m는 근사값이다.

자동 테스트는 코드 동작을 검증한다. 실제 해무 예측 정확도를 입증하는 관측 검증과는 구분한다. 현재 모델은 학습·보정 전의 설명 가능한 규칙 기반 기준선이다.
