# OnSeafog 모델 카드

## 목적과 상태

버전: `onseafog-rules-1.0`. 해운대 주변 이류성 해무에 유리한 조건과 전망 지점의 상대 높이를 탐색하는 규칙 기반 모델이다. 실측 해무 라벨은 제공되지 않았다. 가중치·임계값·높이 오차 범위는 연구용 휴리스틱이며, 학습·보정·성능 검증을 완료한 모델이 아니다.

## 입력과 자료 출처

- 2m 기온 T(°C), 상대습도 RH(%), 이슬점 Td(°C), 10m 풍속 v(m/s), 기상학적 풍향 d(불어오는 방향, °), 해수면 온도 SST(°C)
- 1000, 975, 950, 925, 900, 850hPa 상대습도 및 지오포텐셜 고도(m)
- 모든 시간은 `Asia/Seoul`, UTC+9이다. SST는 배열 위치 대신 KST 시간 문자열로 결합한다. 결측값을 0이나 가상값으로 대체하지 않는다.
- 기상: Open-Meteo GFS (`gfs_seamless`), 해양: Open-Meteo Marine의 SST. 7월은 Historical Forecast API를 사용한다.
- 저장 자료: 2026-07-01 00:00부터 2026-07-31 23:00까지 744시간, 수집시각은 JSON의 `fetchedAt`에 기록한다.
- 저장된 기본 자료의 기상 요청 격자 (35.1595, 129.1604), 실제 격자 (35.203384, 129.14062), 요청 표면고도 0m. 해양 요청 (35.12, 129.16), 실제 (35.125, 129.12502). 재수집 시 실제 격자는 달라질 수 있으므로 JSON 메타데이터를 기준으로 한다.
- 다른 지점은 선택 좌표를 기상·해양 API에 각각 전달한다. 응답의 요청 좌표와 실제 격자를 기록한다. 지형 고도는 자동 추정하지 않으며 관측자가 해발고도를 직접 입력할 수 있다. 이 고도는 기상 입력 격자를 바꾸지 않고 해무층 높이 비교에만 사용한다.
- SST는 약 8km/6시간 해양 모델 자료를 API가 시간별로 보간한 값이다. 해안의 작은 변화와 실측 수온을 그대로 표현하지 못한다.

공식 문서: [Historical Forecast API](https://open-meteo.com/en/docs/historical-forecast-api), [Marine API](https://open-meteo.com/en/docs/marine-weather-api). UI에 데이터 제공자와 지도 출처를 표시한다. 공개·상용 사용 전 해당 제공자의 이용 조건을 확인해야 한다.

## 조건 점수

`clip(x) = min(1, max(0, x))`, `Δ = T − SST`, `D = max(0, T − Td)`이다. 각 항의 기여도를 소수 첫째 자리로 반올림한 뒤 합계를 정수로 반올림한다.

| 항목 | 기여도 |
|---|---|
| 습도 | `30 × clip((RH − 70) / 25)` |
| 공기·바다 온도차 | `25 × clip(Δ / 4)` |
| 이슬점 근접 | `20 × clip(1 − D / 5)` |
| 남동 계열 바람 | `15 × clip(1 − angularDistance(d, 135) / 90)` |
| 완만한 풍속 | `v < 1`이면 `10 × v`, 그 외 `10 × clip((10 − v) / 6)` |

기온이 SST 이하이거나 RH가 80% 미만이면 점수를 최대 39로 제한한다. 해무 조건 활성화는 `점수 ≥ 임계값 AND Δ > 0 AND RH ≥ 80`이다. 초기 임계값은 65, UI 조절 범위는 40–90이다. 점수는 확률이 아니다. 필수 입력이 결측·비정상이면 점수를 미확정으로 남긴다.

## 해무층 상단과 전망 판정

1. 지상 RH가 90% 이상인 경우에만 지상과 연결된 습윤층을 추적한다.
2. 유효한 기압면을 고도순으로 정렬하고, 처음 RH가 90% 미만으로 내려가는 두 점 사이에서 RH=90% 고도를 선형 보간한다. 위쪽에서 다시 습해지는 분리된 층은 포함하지 않는다.
3. 보수적인 비교 범위를 `[max(0, 아래 측정 고도 − 50m), 위 측정 고도 + 50m]`로 둔다. **통계적 신뢰구간이 아니다.**
4. 지상 근처 자료가 부족하거나, 기압면 결측이 있거나, 인접 고도 간격이 650m를 넘으면 미확정이다. 가장 낮은 유효 기압면이 400m보다 높은 경우도 계산하지 않는다. 모든 조회 층이 습윤하면 상단은 미확정으로 남긴다.
5. 해무 조건이 활성화된 경우, 지점 고도가 범위 상단보다 높으면 ‘해무 위 가능’, 하단보다 낮으면 ‘해무 속 가능’, 범위 안이면 ‘해무 아래’로 표시한다. 이 표시는 추정 오차 범위 안에 해당하는 상태이며, 판정 기준은 유지한다. 높이를 특정하지 못하면 ‘해무층 높이 미확정’이다. 조건이 약할 때의 표시는 맑은 시야를 보장하지 않는다.

기본 지점은 아이파크·남천 엑슬루타워·엘시티와 해운대·광안리 해수욕장이다. 건물의 관측 고도는 미입력 상태로 시작하며, 해수욕장은 약 5m를 사용한다. 사용자가 입력한 관측 해발고도(0–2000m)는 좌표별로 현재 브라우저에 저장한다. 실제 지면의 해발고도와 관측 위치 높이를 함께 고려해야 한다. [아이파크 건축가 공개 자료](https://libeskind.com/work/haeundae-udong-hyundai-ipark/)의 T2 건물 높이 292m는 참고 정보이며 관측 고도로 자동 적용하지 않는다. 지점 선택은 건물 출입이나 전망 공간 이용 가능 여부를 보장하지 않는다.

## 한계와 후속 검증

- 상대습도 90%는 포화 및 응결량·가시거리를 직접 측정하지 않는다. 습윤층이 해무라는 보장은 없다. 구름·강수·육상 안개를 분리하는 검증이 필요하다.
- 기압면 간격은 얇은 해무를 놓칠 수 있다. 지오포텐셜 고도와 지형고도 간 차이, 해안 격자·위치의 불일치가 있다. 표시 범위만으로 이 오차가 모두 포함되지는 않는다.
- 좌표별로 조회하더라도 인접 좌표는 같은 기상 격자에 속해 점수가 같을 수 있다. 지형·시선 방향·건물 차폐는 모델링하지 않는다. 수동 지정한 해안 참조점까지의 근사 직선거리를 표시하며 정밀 해안선 GIS 검증은 수행하지 않았다. 관측 고도 미입력 시 높이 판정을 보류하고, 지도 원형 강조는 선택 위치만 나타낸다.
- 풍향 가중치는 해운대 해안 기준이다. 다른 해안의 지형과 방향에 따른 정확도는 검증되지 않았다.
- 과거 예보 아카이브와 해양 모델 자료를 결합한 사후 조건 분석이다. 당시 발행시점에 얻을 수 있었던 입력만 사용한 예측 검증이 아니다.
- 창원 고층 관측, 천리안 2A 영상, 해운대 시정·현장 관측과 시간·공간을 맞춘 독립 라벨이 필요하다. 관측 정의(예: 해안 특정 지점의 시정 기준), 라벨 출처, 품질관리·결측 기준을 먼저 정해야 한다.
- 관측이 확보되면 날짜를 나누어 임계값 조정과 최종 평가를 분리한다. `scripts/evaluate.mjs`는 발생 판정 혼동행렬과 coverage/accuracy/precision/recall/F1을 계산한다. 고도 오차와 지점별 가시성, 예보 리드타임별 성능은 별도로 검증해야 한다.
