## Decisions and remaining work
- User explicitly forbids deployment; keep work local. Run npm.cmd run dev, then visit http://127.0.0.1:4173.
- No observed fog labels were supplied. This is an explainable baseline, not a trained/calibrated probability model; do not claim measured accuracy. observations-template.csv and npm.cmd run evaluate support future labeled evaluation.
- Implemented the physical meaning of the document's altitude comparison: an observer above the estimated fog-top interval is above the fog. The source inequality appears reversed. Fog-top uncertainty and unknown altitude remain explicit.
- Marine SST interpolation and sparse pressure profiles limit precision. Nearby coordinates can share weather grids and scores. Coast distances use manually selected OSM shoreline reference points, not a complete coastline GIS calculation. Presets represent locations and do not guarantee public access or sightlines. Ipark's official 292 m building reference is not observer ASL altitude.
- Remaining integrations from the API plan: ECMWF comparison, keyed KMA/Changwon data, GK2A satellite, and verified mountain AWS sources. Observed fog labels, calibration, and satellite/sounding validation remain unavailable. OSM tiles and uncached coordinate weather require network access.
